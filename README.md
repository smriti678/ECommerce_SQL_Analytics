# E-commerce Database Analysis (SQL)

Quick analytics project focused on database setup and query building using PostgreSQL. Designed a relational model for an e-commerce platform and wrote queries to track key business trends.

## Skills Used
* Relational schema creation with Foreign Keys
* Aggregations & multi-table JOINs
* Filter clauses (GROUP BY, HAVING)
* Advanced ranking via Window Functions (DENSE_RANK)

## Analytics Solved
* Total revenue breakdown across product categories
* Average order values by city (Kathmandu vs Pokhara markets)
* Transaction choices comparing Digital Wallets and Cash on Delivery splits
* Customer retention checking for returning high-value shoppers
* Top selling product items ranked directly inside their own categories
